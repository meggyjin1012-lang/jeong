# 수원 의정 아카이브

『수원시의원으로 살다』 Ⅱ장 「수원시의원들의 사회적 배경」(황병주·유상희)의 도판과 연구를 바탕으로 만든 디지털 아카이브 사이트입니다.

## 폴더 구성
- `docs/` — 공개용 사이트 (시안 A 「컬러풀 에디토리얼」 기반)
  - `index.html` 홈 · `collection.html` 컬렉션 · `exhibition.html` 디지털 전시 · `about.html` 소개
  - `assets/data.js` 소장 자료 목록 — 자료를 추가하면 컬렉션·검색에 바로 반영됩니다
  - `files/` 원문 PDF
- `claude/aks-webpubulish/upload/` — 원본 PDF와 디자인 참고 이미지
- `claude/aks-webpubulish/mockups/` — 디자인 시안 3종(A·B·C)

## GitHub Pages로 공개하기
1. 이 브랜치를 `main`에 병합합니다.
2. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / `/docs`**로 지정하고 Save를 누릅니다.
3. 1~2분 뒤 `https://meggyjin1012-lang.github.io/jeong/` 에서 사이트가 열립니다.
